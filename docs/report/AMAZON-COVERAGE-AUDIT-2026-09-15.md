# تدقيق تغطية أمازون — 15 سبتمبر 2026

## الحالة

**أمازون فقط؛ الإصلاح محلي ولم يُنشر بعد. سامسونج ونون لم تبدأ مراجعتهما.**
**قرار المالك الصريح، 16 سبتمبر:** يُنشر الإصلاح رغم فشل عتبة 70% العامة، لأن
تغطية الفروع 67.6% قبل التغيير وبعده، والفشل سابق ومثبت بقياسين. البوابة من الآن
تمنع انخفاض التغطية الناتج عن التغيير نفسه؛ التساوي أو التحسن لا يحتاج موافقة
إضافية. لم تُعدّل إعدادات Jest أو تُخفّض العتبة. حالة التنفيذ ستُحدّث بعد النشر.
فحص الرحلة قبل النشر اكتمل: **84/108** إجمالاً، و**62/82** لرحلات المقارنة؛
الإخفاقات سجل أساس حي وليست تراجعاً من هذا الإصلاح الذي لم يكن منشوراً وقت الفحص.
[نتيجة الفحص الكاملة](../evidence/amazon-regression-before-2026-09-15.json).

## 1. أداة الجلب والتشغيل

- المسار المجدول المثبت في `pg_cron` يعمل كل ست ساعات: `discover-firecrawl`
  ← Amazon adapter ← `AmazonSearchScraper`. كان يستخدم 11 عبارة وصفحتين لكل عبارة.
- يوجد مسار ثانٍ فعلي: `AmazonScraper` عبر `discover-products` و`update-prices`.
  ملف Python القديم ليس المسار التشغيلي الذي استند إليه هذا التدقيق.
- آخر نجاح كامل في عينة السجلات: run **7132**، اكتشاف، بدأ **06:07:54.801 UTC**
  وانتهى **06:09:10.297 UTC**؛ 88 مكتشفاً و11 جديداً و87 في عداد updated.
  العدادات مأخوذة كما هي، ولا تُجمع باعتبارها مجموعات منفصلة.
- توجد عملية أحدث جزئية: run **7155**، تحديث أسعار، انتهت **08:33:02.953 UTC**،
  111 في عداد updated. صفة partial لا تتحول إلى نجاح كامل لأن `products_failed=0`.
- سبعة الأيام المتحركة تفصيلها في الدليل؛ عدد العمليات ليس معدل تحديث كل منتج.
  لا يوجد سجل في `scraping_schedules` لأمازون، لكن سجلات العمليات وpg_cron موجودة؛
  غياب صف من جدول واحد لا يعني توقف التشغيل.
- إكسترا يستخدم UNBXD المهيكل، والمنيع يستخدم Algolia المهيكل؛ أمازون HTML قابل
  لتغير القالب والحجب. محوّل إكسترا يتتبع رقم العبارة والصفحة، بينما محوّل أمازون
  القديم كان يتتبع رقم العبارة فقط ويتجاوز بقية نتيجتها عند امتلاء الدفعة.
- التعليق القديم بأن المسار المستقل لأمازون «manual only» لا يكفي لإثبات الوضع
  الحالي: السجلات تتضمن عمليات مستقلة حديثة، وإسناد كل واحدة إلى مشغّلها يحتاج
  سجلات runtime إضافية. لم تُعامل التعليقات التاريخية كحقيقة تشغيلية.

## 3. السعر — عشر زيارات فعلية

## 4. عدم الظهور والترتيب

راجعت ADR-183 وADR-204 وADR-305 وADR-310/311/312/313: توجد أسباب سابقة مثبتة
لضياع العنوان، وسعر carousel الخاطئ، وتلوث الملحقات، وفجوات وصول الهوية.
القراءة الحالية لا تبرر إعادة فتح قواعد الهوية لتوسيع النتائج.

المسار الافتراضي في `/api/search` يجمع Algolia وقاعدة البيانات ويطبّق فلاتر
الفئة والملحقات والميزانية والصلة. `compareBySort` يؤخر الملحقات ثم يرتب افتراضياً
بعدد المتاجر ثم السعر؛ الفرز السعري الصريح يستخدم السعر بعد فصل الملحقات.
العروض تخضع أيضاً لـ`isDisplayableRetailer`. لم أجد في هذا الجزء تفضيلاً تجارياً
خاصاً لإكسترا أو المنبع الذي ينتمي إليه العرض، ولم أغيّر حياد الترتيب.

التجميع في `product-grouper` يستخدم fingerprint للعلامة والموديل والسعة والفئة،
ثم fuzzy matching بحد 0.75 لبعض المنتجات غير المجمعة. مسار TPS والربط canonical
منفصلان ولهما بوابات أدلة. عدد 769 المرتبط لا يساوي عدد المقارنات متعددة المتاجر،
ولا عدد النتائج التي تظهر لكل استعلام. فجوة AC ذات 252 low-confidence ظاهرة في
القياس، ولم تُرقّ إلى valid لإظهارها قسراً.

## 5. الإصلاح المحلي وقرار التصميم

1. فصل محوّل أمازون عن المحوّل العام؛ بقيت تعريفات المتاجر الأخرى دون تغيير.
2. أبقى العبارات الـ11 القديمة وترتيبها لقبول حالة الاستئناف القديمة، وأضاف
   عبارات صريحة للأفران والآيباد وأنواع اللابتوبات وملحقاتها والأجهزة المنزلية.
   القائمة الآن 26 عبارة، ولا يعد ذلك قياس نمو في الكتالوج.
3. حالة استئناف مرقمة للعبارة والصفحة والموضع داخل الصفحة؛ لا تتجاوز بقية صفحة
   ثابتة عند امتلاء الدفعة. نتائج أمازون قد تعيد ترتيب نفسها بين طلبين، لذلك
   لا ندعي ضمان لقطة ثابتة من المصدر أو تغطية كل ASIN.
4. حد صفحتين لكل عبارة وثماني صفحات لكل استدعاء، وانتظار بين الطلبات، لمنع دورة
   كبيرة غير محدودة. التغطية الأوسع تحتاج دورات مجدولة أكثر؛ مدة دورة كاملة بعد
   النشر لم تُقَس بعد.
5. إخفاق HTTP أو قالب بلا نتائج قابلة للتعرف يعاد كخطأ ويحتفظ بموضع الاستئناف؛
   لا يتحول إلى نجاح فارغ. صفحة no-results المعروفة تبقى نهاية طبيعية.

جلب حي محلي باستخدام **الكود الفعلي المعدل** أعاد ثلاث نتائج لكل من أربع عبارات:
electric oven، gas cooker، built in oven، laptop charger.
[أسماء وأسعار وروابط النتائج](../evidence/amazon-source-probes-2026-09-15.json).
هذا يثبت الوصول للمصدر، **ولا يثبت وصولها إلى بحث الإنتاج بعد النشر**.

البدائل المرفوضة: تخفيف بوابات الهوية، تفضيل أمازون في الترتيب، تعديل المحوّل
المشترك لكل المتاجر، جلب غير محدود، إضافة API مدفوع أو مفاتيح غير متاحة، أو اعتبار
توسع إعدادات روابط المسار المستقل إصلاحاً للمسار المجدول المختلف.
