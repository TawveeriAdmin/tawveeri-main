## ما عُدّل
1. **الرسالة** أصبحت تُرسم من الملخص اليومي نفسه الذي يحفظه المركز (`founder_summaries`)، بالترتيب المطلوب: العنوان «ملخص توفيري اليومي — [التاريخ]» ← ماذا حدث أمس (متصفحات لا أشخاص، نية شراء، نتائج غير فارغة بالبسط والمقام، خروج مرتبط ≠ زيارة أو شراء، أعلى الاحتياجات/المنتجات/المتاجر) ← المال مفصولًا (مصروف مدفوع أمس وهذا الشهر، التزامات متوقعة بانتظار التأكيد، مقبوض، معتمد، معلق «ليس إيرادًا مقبوضًا»، وغير المعلوم «غير معلوم» لا صفر) ← أهداف الشهر (الحالة، الحالي/الهدف، الموعد) ← جودة البيانات إن وجد ما يؤثر ← **قرار اليوم** إجراء واحد ← رابط `https://tawveeri.com/founder`. نسخة نصية مرفقة مع HTML.
2. **سجل الإرسال** `founder_email_sends` (ترحيل 62): صف لكل محاولة (مرسل/مكرر/فشل/محظور/غير مهيأ/تجربة) مع نسخة HTML المرسلة ومعرّف الرسالة وحالة المزود؛ فهرس فريد يمنع رسالتين «مرسلتين» لليوم نفسه.
3. **الفشل الهادئ**: أي جزء يتعذر حسابه يظهر «غير متاح» وتُرسل الرسالة الحتمية؛ لا رسالة فارغة ولا استثناء تقني. تفسير الذكاء الاصطناعي يظهر فقط إن نجح وتم التحقق منه.
4. أعلام للتشغيل اليدوي: `?dryRun=1` (عرض وتسجيل بلا إرسال)، `?kind=test` (رسالة اختبار للمؤسس لا تستهلك حصة اليوم)، `?force=1`.

## ما لم يُعدّل
الجدولة والخدمة والمستلم (كانت صحيحة)، التتبع، المنتجات، الترتيب، الحملات، المصروفات.
