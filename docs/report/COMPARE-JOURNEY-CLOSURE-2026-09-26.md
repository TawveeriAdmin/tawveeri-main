## 5. حالة كل محور

| المحور | الحالة |
|---|---|
| إصلاح العرض (صفحة المقارنة، المتعددة، المنتج، البحث) | **نُشر وثبت حيًا** (القسم 6) |
| صحة الهوية (LG Fresh/FreshDV، سامسونج الثلاثية) | **نُشر**؛ عرض المنيع رُحّل حيًا؛ ظهور المعرّف الجديد `Fresh` **بانتظار إثبات تشغيلي** (دورة التغذية والتطبيع التالية)؛ 9,882 معرّفًا بلا هوية **قرار معماري مفتوح** |
| الروابط (القديم 308، الدرج، البطاقات) | **نُشر وثبت حيًا** |
| التحديث التشغيلي للشركاء | **لم يُنفَّذ** — مقاس ومصنّف؛ خيارات السعة في ADR-379 قرار للمؤسس؛ Creators API لم يُعد فتحه |
