# إعلان «جهّز بيتك بذكاء» — شدّ الحبل على الميزانية (v2)

**التصنيف الحالي: نسخة مونتاج تنتظر التعليق الصوتي.** الصورة والموسيقى والمؤثرات والنص المدمج مكتملة (9:16، 1080×1920، 30 إطار/ث، 31.5 ث). سطر الصوت السعودي يُولَّد خارج هذه البيئة عبر Flow بالطلب الجاهز في `VO-SCRIPT.md`، ويُدمج بأمر واحد (`build/mix_vo.py`).

| الملف | الوصف |
|---|---|
| `tawveeri-jahhez-baytak-9x16.mp4` | نسخة المونتاج (موسيقى + مؤثرات + نص مدمج، بلا تعليق صوتي) |
| `cover.png` | الغلاف المصحح (1080×1920) |
| `captions.srt` | ترجمة عربية على توقيتات التعليق الصوتي (مولّدة من `VO_CUES` في `build/scenes.py`) |
| `VO-SCRIPT.md` | طلب التوليد الجاهز لـ Flow + النص بالتشكيل + قيود المدة + أمر الدمج |
| `CAPTIONS-PLATFORMS.md` | كابشن تيك توك وX + رابط UTM |
| `build/` | **ملف المشروع القابل للتعديل**: `scenes.py` (الخط الزمني والمشاهد)، `characters.py` (الشخصيات والمؤثرات)، `audio.py` (الموسيقى والمؤثرات الصوتية)، `render.py` (الإخراج)، `mix_vo.py` (دمج الصوت) |
| `assets/` | الشعار الأصلي كما ورد، وخطوط Tajawal (OFL) |

## ما تغيّر في v2

- **حركة لها وزن:** محرك «الشدّة» (`pull_state`): كل جهاز يتحفّز (انكماش) ثم يشدّ (تمدد)، فيجذب الميزانية والعريس ناحيته، والعريس يقاوم بميل الجسم وانزلاق القدمين مع خطوط انزلاق وقطرات عرق. تنافس متناوب في الافتتاح، ثم متسارع في التصاعد حتى شدّة جماعية تكسر الميزانية.
- **تعبيرات أوضح:** جفون وحواجب حسب الحالة (جهد بعينين معصورتين وأسنان مضغوطة، صراخ، صدمة، رضا، حزن مع دمعة، دوخة بعينين حلزونيتين)، وأذرع وأرجل للأجهزة تمسك الحبال وتتثبّت بالأرض.
- **تصاعد كوميدي ولحظة انكسار:** العريس يُقذف للخلف ويهبط جالسًا مع غبار ونجوم دوّارة؛ الثلاجة تعانق قطعتها، المكيف يدور دورة كاملة ويأخذ قطعته بغرور، والغسالة تحمل شريحة صغيرة: «وأنا؟!».
- **انتقال محسوس:** شعار توفيري يهبط كختم ثقيل (انضغاط ثم ارتداد)، موجة صدمة تدفع الفوضى خارج الكادر، ثم يغمر الأخضر الشاشة.
- **الواجهة الحقيقية مقربة ومقروءة:** أربع لقطات مع دفع كاميرا بطيء وحلقات ذهبية على العنصر المقصود (عدد المكيفات، الميزانية 15000 ثم «ابن الخطة»، سعر المكيف 2,766، أيقونة المشاركة)، وتحذير الواجهة الأصلي ظاهر في لقطة الخطة.
- **الحل:** قطع «كم؟» تطير وتلتحم في شريط واحد بنِسَب الخطة الفعلية، تتبدّل أوسمتها إلى «التكييف ×2 · الثلاجة · الغسالة»، وتقفز الأجهزة فوق نصيبها. «كلٍّ أخذ نصيبه… وخطة أجهزتك جاهزة».
- **النص والتوقيت أُعيد ضبطهما معًا:** 11 سطرًا قصيرًا بنوافذ 1.4–2.8 ث؛ السطر الطويل قُسم (الخطة في لقطة، المشاركة في لقطة). حُذف تكرار «كل جهاز أخذ نصيبه»؛ الختام سطر تحفظ واحد فقط.
- **الغلاف:** العنوان «كل جهاز يبي الميزانية له!»، الشريط أسفل فقاعة الغسالة، الشعار مفصول عن النص بفاصل.

## دقة الرسالة (ثابتة من v1)

لا ادعاء سعر أو توفير؛ «المتبقي ليس توفيرًا مثبتًا» ظاهر في الواجهة؛ الشراء لدى المتاجر مذكور؛ النطاق أجهزة البيت؛ الشخصية رسوم؛ الأسعار من التسجيل دون تعديل مع سطر «كما رُصدت وقت التسجيل»؛ الموسيقى والمؤثرات مركّبة برمجيًا (حقوقها لتوفيري).

## الجودة بصراحة

التسجيل المرفق 576×1024؛ لقطات الواجهة مكبّرة 1.3–1.5× مع تحديد خفيف. تسجيل أعلى دقة يُستبدل في `scenes.py` (`UI_SHOTS`) دون تغيير المونتاج.

## إعادة الإنتاج

```bash
pip install pillow numpy imageio-ffmpeg
FF=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
for seg in "A 7.2" "B 14.0" "C1 16.6" "C2 21.2"; do set -- $seg; mkdir -p ui/$1
  $FF -ss $2 -t 3.6 -i screen-recording.mov -vf fps=30 ui/$1/%03d.png; done
AD_UI_DIR=$PWD/ui python3 build/render.py out/
python3 -c "import sys; sys.path.insert(0,'build'); import scenes; scenes.cover().save('cover.png')"
```
