# التعليق الصوتي — نص وتوقيت ونطق

الصوت المطلوب: رجل سعودي، عشرينيات/ثلاثينيات، طبقة دافئة وعفوية (مو مذيع). الإيقاع سريع في النصف الأول، مرتاح في النصف الثاني. كل سطر جملة قصيرة تُقال بنفَس واحد.

**أداة مقترحة:** Azure Speech (`ar-SA-HamedNeural`) أو ElevenLabs بصوت سعودي، أو ممثل صوت. أُدخل النص **بالتشكيل الموضّح** أدناه ثم راجع النطق قبل الاعتماد.

## تنبيه نطق (من التجربة السابقة)

- «أَبِي أَجَهِّز بيت»: الهاء **مشددة ومكسورة** — «أَجَهِّز»، بلا واو. لو تعثّر النطق في الأداة، بدّل الجملة إلى: «أبي أكمّل بيت… مو جهاز!» (البديل مسجّل هنا كخيار معتمد).
- «جَهِّز بيتك»: الهاء نفسها مشددة مكسورة.
- «كلٍّ» تُنطق «كُلِّن» (تنوين كسر) — بديل أسهل: «كل واحد أخذ نصيبه».

الفقاعات «لي!» / «لا، لي!» / «أنا اثنين!» / «وأنا؟!» تبقى مكتوبة فقط (أصوات الأجهزة مؤثرات). إن رغبت بتسجيلها: أصوات مضحكة مضغوطة (نبرة سريعة، pitch مرتفع للغسالة ومنخفض للثلاجة)، مدة كل واحدة ≤ 0.5 ث، عند 0.35 / 1.35 / 0.85 / 7.35 ث.

## الدمج بعد التسجيل

سجّل السطور في ملف واحد `vo.wav` (48 كيلوهرتز) مع الصمت بينها بحسب التوقيت أعلاه (أو ملفًا لكل سطر وركّبها بالتوقيت)، ثم:

```bash
ffmpeg -i tawveeri-jahhez-baytak-9x16.mp4 -i vo.wav -filter_complex \
  "[0:a]volume=0.45[bed];[bed][1:a]amix=inputs=2:duration=first:normalize=0,alimiter=limit=0.95[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -movflags +faststart \
  tawveeri-jahhez-baytak-9x16-vo.mp4
```

قبل الاعتماد: اسمع السطر 4 مرتين (أجهِّز)، وتأكد أن نهاية السطر 11 لا تتجاوز 28.2 ث.

## إعادة البناء (المقاطع الأربعة من التسجيل)

```bash
FF=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
SRC=screen-recording.mov   # التسجيل الأصلي 576×1024
for seg in "A 7.2" "B 14.0" "C1 21.0" "C2 24.7"; do set -- $seg; mkdir -p ui/$1
  $FF -ss $2 -t 2.6 -i $SRC -vf fps=30 ui/$1/%03d.png; done
AD_UI_DIR=$PWD/ui python3 build/render.py out/
```
